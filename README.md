**Denitrifying Polyphosphate Accumulating Organisms Omics Database (DPAO-OmicsDB)** is a curated genome database designed to comprehensively archive putative polyphosphate-accumulating organisms (PAOs). The database integrates PAO genomes recovered from a wide range of complex ecosystems, including engineered systems (e.g., wastewater treatment plants) and natural environments such as freshwater lakes, salt marsh wetlands, and estuarine-coastal bays.  

Each genome entry is annotated with detailed metadata, including:  
- Habitat source  
- Taxonomic classification  
- Genome quality metrics  
- Copy number of key functional genes involved in phosphorus metabolism, denitrification, and fermentation.    

**DPAO-OmicsDB** aims to serve as a centralized genomic resource to supporting systematic comparative analyses of PAO diversity, functional potential, and ecological adaptation across contrasting environments.
